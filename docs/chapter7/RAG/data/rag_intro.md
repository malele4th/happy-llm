# RAG 检索增强生成

RAG（Retrieval-Augmented Generation）是一种结合检索与生成的大模型应用架构。

## 核心流程

1. **索引**：将文档库分割成较短的片段，并通过编码器构建向量索引。
2. **检索**：根据问题和片段的相似度检索相关文档片段。
3. **生成**：以检索到的上下文为条件，生成问题的回答。

## 主要模块

- 文档加载与切分：读取 pdf、md、txt 等文件并切分为 chunk。
- Embedding 模型：将文本转换为向量表示。
- 向量数据库：存储文档片段及其向量。
- 检索模块：根据用户问题检索最相关的文档片段。
- 大模型模块：根据检索到的上下文回答用户问题。

RAG 的优势是可以让大模型基于外部知识库回答，减少幻觉，并支持知识更新而无需重新训练模型。
